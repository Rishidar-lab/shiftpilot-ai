# Evidence Ledger — ShiftPilot

Connects Week-1 internship requirements to concrete implementation
evidence. Same structure as SourceLens's `docs/EVIDENCE_LEDGER.md`, applied
to this project's actual requirements and code. Nothing here is marked
PASS without a file, test, or command a reviewer can independently check.
This ledger complements — it does not replace — the more detailed
`docs/week1-submission-matrix.md`, which carries the full verification
narrative and dated re-verification history.

Statuses: **PASS** (implemented and verified), **MEASURED LIMITATION**
(implemented, with a known, disclosed boundary — not a defect),
**EXTERNAL ACTION** (requires something outside this repository — an
account, hardware, or a manual step), **OPEN FINDING** (a real,
unresolved issue that needs attention).

## OPEN FINDING, flagged prominently

`docs/week1-submission-matrix.md` (written before this session, unchanged
by it) records: _"Revoke the OpenRouter key that was used during
verification. It was pasted into a chat transcript and, checked on
2026-08-18, is still active."_ This is a real, unresolved credential
exposure. It does **not** affect the live deployment (which uses a
separate key stored only in Render's secret store), but the exposed key
itself is still valid as far as the repository's own records show and
this review has no way to check or revoke it — that requires the
OpenRouter account. **This needs to be revoked before submission,
independent of anything else in this ledger.**
